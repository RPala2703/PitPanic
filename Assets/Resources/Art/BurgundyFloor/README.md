# Pit Panic Burgundy Floor Pack

Included files:
- `Burgundy_Casino_Floor_Tile_Atlas.png` — floor and trim tile atlas matching the Pit Panic burgundy casino style.

Suggested use:
- Use the plain burgundy tiles for open walkable space.
- Use the patterned tiles for main carpet areas and focal zones.
- Use the gold-trim edge and corner tiles for borders, wall trims, and room framing.
- Use the curved and junction tiles for custom paths, aisles, carpet runners, and feature areas.

This pack is intended as a visual asset reference / atlas for implementation in-engine.
